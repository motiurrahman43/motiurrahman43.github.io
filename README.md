# Md. Motiur Rahman — GIS & Remote Sensing Portfolio

A responsive, static personal portfolio website designed for GitHub Pages.

## Files
- `index.html` — all portfolio sections and content
- `style.css` — responsive dark navy / cyan visual design
- `script.js` — interactive navigation, project filters, detail modals and scroll progress
- `assets/` — supplied profile, RTK and UAV photos, generated hero background and CV PDF

## Publish on GitHub Pages
1. Open `https://github.com/motiurrahman43/motiurrahman43.github.io`.
2. Download this ZIP and extract it on your computer.
3. Upload the contents of the extracted `motiur-gis-portfolio` folder to the **root** of the repository (so `index.html` is at repository root).
4. Commit the changes to the `main` branch.
5. Open repository **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
7. After the deployment completes, visit `https://motiurrahman43.github.io`.

GitHub Pages may take several minutes to publish the first version.

## Customize
- Update text in `index.html`.
- Replace images in `assets/` while keeping the same filenames, or update their paths in the HTML.
- Adjust colors and layout in `style.css`.
- Interactions are in `script.js`.

## Notes
- This is a static website: it does not require a backend or paid hosting.
- The contact button opens the visitor's email application using the email address listed in the CV.
- Check all public contact details and CV contents before publishing. GitHub Pages websites are publicly accessible.
